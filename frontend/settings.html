Single Title

Article generation pipeline

1
Fetch metadata from Tubi
Pulls title, year, description, directors, cast, tags, rating, and image URLs from Tubi's content API using the content ID.
2
Generate article with Claude
Fills the user prompt template with the metadata, then sends system + user prompt to Claude. Generates headline, subheadline, intro, cast bios, pull quote, and "why watch it."
Claude Sonnet 4.6 (Bedrock)
3
Quality gate
Checks for banned words, em dashes, minimum word count, headline length, and sentence case. Fails the attempt and retries with feedback if any rule is violated. Up to 4 retries.
4
Brand alignment check
GPT-4o scores the article across 5 dimensions: voice, specificity, angle, energy, and consistency. Scores below 3.5/5 trigger a retry with the scoring notes as feedback.
GPT-4o (OpenAI)
5
Save to database
Stores the final output, brand score, metadata, and status in SQLite. Article appears in the Articles list as a draft.
Listicle

Listicle generation pipeline

1
Select containers
Fetches Tubi's full homepage container list. GPT-4o-mini picks the 3–5 containers most relevant to the article angle.
GPT-4o-mini (OpenAI)
2
Fetch titles from containers
Pulls all titles from the selected containers via Tubi's tensor API — up to 200 titles per container including metadata, ratings, cast, and directors.
3
Select titles
GPT-4o-mini reviews the full candidate list and selects 10–12 titles that best support the article angle. Returns IDs with reasoning.
GPT-4o-mini (OpenAI)
4
Generate listicle with Claude
Sends the title list and container description to Claude with the full listicle prompt. Generates headline, subtitle, intro, and a blurb with tease for each entry.
Claude Sonnet 4.6 (Bedrock)
5
Quality gate + brand check
Same quality gate and brand alignment check as single titles. Up to 4 retries with failure feedback appended to the prompt.
GPT-4o (OpenAI) for brand check
6
Save to database
Stores the final listicle output including all entries, brand score, and metadata. Article appears in the Articles list as a draft.
